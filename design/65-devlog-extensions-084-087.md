# devlog 확장 설계 (spec 084~087, 마이그레이션 없음)

작성 2026-10-11 · 저장소 동기화·다국어 점검. [64 devlog 확장 설계](./64-devlog-extensions-077-083.md)에 이어, 그 뒤 devlog에서 공통 설계(테이블·API·구조·권한)를 바꾼 기능만 모았습니다. 팀 공통 설계(01~53, 통합 ERD V1)는 그대로 두었습니다. 기능의 세부 규칙과 화면은 코드 저장소의 기능 명세 `specs/NNN-*`이 기준입니다.

근거: [devlog CHANGELOG](https://github.com/AIGJ-01-002-blog/devlog/blob/main/CHANGELOG.md) v1.61.2~v1.64.2. 이 기간에는 마이그레이션이 없어 ERD는 V31 그대로입니다.

## 1. 기능별로 바뀐 공통 설계

| spec | 기능 | 버전 | 테이블 | API | 권한·구조 |
|---|---|---|---|---|---|
| 084 | 화면 코드의 tsc `.js` 사본 지우기 | 1.61.2 | 없음 | 없음 | 빌드 구조만. `tsconfig.json`의 `noEmit`, `.gitignore`의 `src/**/*.js`로 사본이 다시 생기거나 커밋되지 않게 함 |
| 085 | 애드센스 "가치가 별로 없는 콘텐츠" 대응 | 1.62.0 | 없음 | 화면 `/terms`·`/privacy`를 서버가 본문까지 그림, `GET /api/site/policies/{terms\|privacy}`(그 밖의 값은 404) | 문안은 서버의 `policy/terms.html`·`policy/privacy.html` 한 곳. 사이트맵에 포함. 공개 글이 2편 미만인 태그 화면은 `noindex` |
| 086 | AI가 쓴 글의 비밀값 막기 | 1.63.0 | 없음 | MCP 도구 동작만 바뀜(아래 2절) | 찾은 값은 응답·로그에 다시 쓰지 않고 종류만 적음. 웹에서 사람이 직접 발행하는 글은 막지 않음 |
| 087 | 설정 › AI 연결의 앱별 연결 안내 | 1.64.0, 1.64.1 | 없음 | 없음 | 화면만. 로그인 연결(ChatGPT·Claude 앱, OAuth)과 토큰 연결(Claude Code·Cursor·Codex)을 나눠 안내 |
| 081 갱신 | 약관 화면 틀 번역 | 1.64.2 | 없음 | 없음 | 약관·처리방침 본문은 한국어 원문만 두고 제목·시행일·링크와 "원문만 있어요" 안내만 화면 언어로 보임 |

## 2. 권한 매트릭스에 더해진 것

[42 권한 매트릭스](./42-permission-matrix.md), [64 §2](./64-devlog-extensions-077-083.md#2-권한-매트릭스에-더해진-것)에 더해, AI 연결(MCP) 도구가 글에 비밀값(토큰·API 키·개인 키·JWT·주소 속 비밀번호·주민등록번호)이 보일 때:

| MCP 도구 | 비밀값이 없을 때 | 비밀값이 보일 때 |
|---|---|---|
| `publish_post` (AI 발행 허용 회원) | 발행 | 발행하지 않고 실패로 돌려줌 |
| AI 일기 자동 발행 | 발행 | 임시글로 둠 |
| `add_note` | 메모 저장 | 받지 않음 |
| `create_draft`·`write_devlog`·`update_draft` | 임시글 저장 | 임시글 저장, 결과에 주의 문장 |

## 3. 다국어 범위 (spec 081 기준, 2026-10-11 점검)

| 대상 | 언어 | 비고 |
|---|---|---|
| 화면 문장(관리자 화면 제외) | 한국어·English·日本語·中文 | 한국어 문장을 키로 쓰는 사전 `locales/en·ja·zh.ts`, 키 1,354개. `i18n.test.ts`가 빠진 키·자리표시 불일치를 잡음 |
| 관리자 화면 | 한국어 | 운영자만 써서 번역하지 않음 |
| 약관·처리방침 본문 | 한국어 | 법적 검토 뒤 번역본(일일 보고 질문) |
| 서버 오류 문장 | 한국어 | 다음 단계: `Accept-Language`로 고르기 |
| 글 본문·제목·태그·닉네임 | 쓴 그대로 | 번역하지 않음 |
| 코드 저장소 README | 한·영·일·중 4판 | `scripts/check-readmes.py`가 구조·릴리스 표·버전을 맞춤, 조직 프로필(.github)도 같은 내용 |
| 설계 문서(이 저장소)·기능 명세 `specs/` | 한국어 | 팀 문서라 한국어판만 둠 |
