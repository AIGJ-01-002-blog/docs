작성 2026-10-08 · 화면 개편은 spec 048(v1.24.0). 민서님 방향(트렌디한 개발 블로그, AI 기능 확대, MCP, 인프라·전산학 유료 글)을 받아 Claude가 고른 추천안입니다.

**"AI 에이전트가 읽고 쓰는 개발 블로그"** 로 포지셔닝합니다. velog와 기능 개수로 겨루지 않고, ① 글을 의미로 찾아 주는 검색·추천, ② Claude·Cursor 같은 AI 도구에서 바로 쓰고 읽는 MCP 서버, ③ 그 위에 얹는 유료 시리즈(인프라 실전·전산학 기초)로 차별화합니다.

## 2. AI 기능: 민서님이 이미 해 본 기술 순서대로

민서님 경험(Spring AI, Gemini→Ollama 전환, 배치, 임베딩 검색, 챗봇, 12GB GPU 파인튜닝)을 그대로 쓰는 순서입니다.

| 순서 | 기능 | 쓰는 기술 | 왜 먼저인가 |
|---|---|---|---|
| 1 | **의미 검색 + 관련 글 추천** | 발행 이벤트 → 임베딩 배치 → PostgreSQL `pgvector`. 지금 전문 검색과 섞는 하이브리드 | 모든 AI 기능의 바탕(검색·챗봇·유료 추천이 다 이 벡터를 씀). 이미 해 본 기술 |
| 2 | **글쓰기 도우미** | 제목 3안, 요약, 맞춤법·문장 다듬기, 코드 블록 설명. 지금 AI 태그 추천의 Gemini→Ollama 전환 구조 재사용 | 쓰는 사람이 바로 체감. 실패해도 글쓰기는 그대로 |
| 3 | **"이 블로그에 물어보기" 챗봇** | 블로그·시리즈 단위 RAG, 답에 근거 글 링크 표시 | 유료 시리즈의 핵심 혜택이 됨 |
| 4 | **나만의 작은 모델** | 12GB로 QLoRA(7~8B 한국어 모델) — 태그·요약 문체를 devlog 글로 미세 조정, 임베딩은 `bge-m3` 같은 다국어 모델을 Ollama로 | 포트폴리오 가치가 큼. 다만 1~3이 데이터를 쌓아야 의미가 있음 |

### 집 PC GPU 붙이는 방법 (설정만 바꾸면 되게)

- 앱은 AI 공급자를 **설정값 목록**으로만 압니다: `AI_PROVIDERS=gemini,ollama-home,ollama-local`. 순서대로 시도하고 한도·오류면 다음으로 넘어갑니다(지금 태그 추천 구조 확장). 공급자마다 글이 어디로 가고 얼마나 보관되는지, 실패하면 다음 공급자로 다시 보낸다는 점을 AI 동의 문구와 개인정보 처리방침에 적고, 동의 범위에 없는 공급자에는 보내지 않습니다(지금 동의 문구는 Gemini만 적혀 있어 집 PC·로컬 Ollama를 넣을 때 함께 고칩니다).
- 집 PC의 Ollama는 이미 운영 중인 **Cloudflare Tunnel**로 `ai.devlog.life` 같은 주소에 열고, Cloudflare Access 서비스 토큰으로만 들어오게 합니다. 앱은 `OLLAMA_BASE_URL`과 토큰 두 값만 바꾸면 됩니다.
- PC가 꺼져 있으면 자동으로 다음 공급자 또는 "AI 없음"으로 내려가고, 무거운 일(임베딩 재계산)은 큐에 쌓였다가 PC가 켜지면 처리합니다.

## 3. MCP: 두 방향 다, 순서는 "서버 먼저"

**① devlog MCP 서버 (crowfoot처럼)** — 가장 추천합니다.

Claude Code·Claude 데스크톱·Cursor에서 "오늘 고친 버그 TIL로 정리해서 devlog 초안 올려 줘"가 되는 것이 차별점입니다.

**구현됨 (spec 052, v1.27.0)**: 2026-10-08 민서님 답(5번)대로 모든 회원에게 열었습니다. 핵심 도구는 민서님 아이디어인 `write_devlog`(AI가 그날 작업을 개발 일지로 정리해 임시글로 올림)입니다.

| 도구 | 하는 일 | 권한 |
|---|---|---|
| `write_devlog` | 오늘 대화·커밋을 개발 일지 임시글로 | 쓰기 |
| `create_draft` / `update_draft` | 임시글 만들기·고치기 (발행한 글은 못 고침) | 쓰기 |
| `request_publish` | "발행 대기" 표시 + 편집 화면 링크. 발행은 사람이 [발행하기] | 쓰기 |
| `search_posts` | 공개 글·내 글 검색 | 읽기 |
| `get_post` | 글 본문(Markdown). 웹과 같은 공개 범위 | 읽기 |
| `list_my_posts` | 내 임시글·발행 글 목록 | 읽기 |
| `list_tags` | 내가 자주 쓴 태그·인기 태그 | 읽기 |

- 주소 `POST /api/mcp` (Streamable HTTP, 상태 없는 JSON 응답). Spring AI 스타터 대신 직접 구현했습니다: 도구가 8개뿐이고, 기존 서비스(글 저장·권한 검사)를 그대로 부르며, Spring Boot 4 호환을 기다릴 필요가 없습니다.
- 인증은 두 가지입니다. Claude Code·Cursor·Codex는 설정 › AI 연결에서 만드는 **개인 접근 토큰**(`dvl_…`, 읽기 또는 쓰기, 30·90·365일, 회원당 10개, DB에는 SHA-256만). ChatGPT 커넥터(와 Claude 웹 커넥터)는 토큰을 넣을 칸이 없어서 **OAuth 로그인**(동적 등록 + PKCE, devlog 동의 화면에서 [허용])으로 붙습니다. 세션 쿠키는 보지 않습니다.
- 발행·공개 범위 변경·삭제 도구는 **없습니다**. AI는 임시글과 "발행 대기"까지만 만들고, 기존 발행 API는 로그인한 사람만 부를 수 있으므로 MCP로 사람 확인을 건너뛸 수 없습니다.
- 요청 제한: 회원당 1분에 60번, 쓰기 도구는 한 시간에 30번. 쓰기 도구는 이메일 인증을 마친 회원만. 정지·탈퇴 대기 계정은 403.
- AI가 붙인 태그 제안은 발행 창에 미리 채워지고, 발행 요청이 있으면 편집 화면 위에 알림이 뜹니다.

**② MCP 클라이언트로 기능 넓히기** — 서버 다음에.

- GitHub MCP를 붙여 "이번 주 커밋·PR로 회고 초안 만들기".
- 유료 인프라 시리즈의 "따라 하기" 단계에서 독자의 설정 파일을 검사해 주는 도우미(예: compose·Tunnel 설정 점검).

## 4. 유료 콘텐츠: 결제보다 "유료 글 구조"를 먼저

| 단계 | 내용 | 외부 가입 필요 |
|---|---|---|
| A | 공개 범위에 **"멤버십 전용"** 추가, 앞부분 미리보기 + 잠금 화면. 관리자가 수동으로 권한 부여 | 없음 |
| B | **시리즈 단위 판매**(한 번 구매) + 월 멤버십. 유료 회원 혜택: 전 글 열람, 시리즈 챗봇, MCP 쓰기 도구 | 결제 대행사(PG), 사업자 등록 |
| C | 다른 작성자도 유료 시리즈를 팔 수 있게(수수료) | 정산·세금 처리 |

첫 유료 시리즈 후보 (우리가 실제로 해 본 것이라 바로 쓸 수 있음):

1. **"무료로 서비스 띄우기"** — Oracle 무료 VM, Cloudflare Tunnel·도메인, Docker Compose, GitHub Actions 배포, SonarQube
2. **"Spring AI 실전"** — Gemini 무료 키 → Ollama 전환, 임베딩 검색, RAG 챗봇, MCP 서버 만들기
3. **"전산학 기초 다시 보기"** — 운영체제·네트워크·DB를 실제 devlog 코드(인덱스, 트랜잭션, 캐시)로 설명

무료 맛보기 1~2편 + 나머지 유료로 두면 검색 유입이 유료 전환으로 이어집니다.

## 7. 결제를 붙일 때 (민서님 답 3·3-1·9번)

지금은 모든 글이 열려 있고 결제 코드는 없습니다. 결제를 시작하기로 하면 이 순서로 진행합니다.

1. **사업자 등록 (민서님이 직접)**: 온라인 콘텐츠·구독 판매라 업종은 정보통신업 계열(예: 응용 소프트웨어 개발·공급, 온라인 정보 제공)로, 처음에는 **개인 간이과세자**를 추천합니다(매출이 작을 때 부가세 부담이 가볍고, 커지면 일반과세자로 바뀝니다). 다만 PG사 중에는 간이과세자 심사가 까다로운 곳이 있어, 등록 직전에 국세청 홈택스와 PG사의 최신 조건을 함께 확인해 정합니다. 온라인 판매라 **통신판매업 신고**도 필요합니다.
2. **결제 대행사(PG)**: 추천은 **토스페이먼츠 단독 계약**(개발 문서·테스트 키가 좋고 정기 결제 지원). 여러 PG를 바꿔 끼울 가능성이 있으면 **포트원**을 앞에 둡니다. 가입·계약은 민서님이 하고, Claude는 테스트 키로 먼저 붙입니다(키는 실행 환경 비밀값으로만).
3. **유료 구조**: 공개 범위 "멤버십 전용" + 앞부분 미리보기·잠금 화면(단계 A)을 먼저 넣고, 결제가 열리면 시리즈 단위 판매·월 멤버십(단계 B)으로 잇습니다.
4. **AI 이용권 약 1,990원 (답 9번)**: 결제와 함께 소액 이용권(AI 다듬기·챗봇 등 서버 비용이 드는 기능)으로 넣습니다. 결제 전에는 관리자가 회원에게 이용권을 수동으로 부여합니다. 참고로 MCP `write_devlog`는 글을 쓰는 AI 비용을 사용자 쪽 AI 도구가 내므로 이용권 없이도 씁니다.
